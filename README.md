## Publicação no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `isa-portfolio`.
2. Envie todos os arquivos deste pacote para o repositório.
3. No GitHub vá em **Settings** → **Pages**.
4. Em **Source** escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve. O GitHub vai gerar um link do tipo:

   `https://seu-usuario.github.io/isa-portfolio/`

Lembre-se de editar o e-mail, GitHub e outros links diretamente no `index.html`.
